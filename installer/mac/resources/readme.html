What gets installed

This installer sets up:

  • Buddy, in DaVinci Resolve's Workspace > Scripts menu
  • Python 3.13 from python.org - only if this Mac doesn't already have Python 3.10 or newer from python.org
  • The Python packages Buddy uses (PySide6, Pillow, NumPy, openpyxl, pynput, PyMuPDF, cryptography) - only the ones that are missing

Anything missing is downloaded while installing - up to about 330 MB, so it needs an internet connection and can take a few minutes.

Transcription (Whisper) is set up later from inside Buddy, only if you want it.

DaVinci Resolve: the free Resolve runs Buddy on version 21.0.x and earlier. From 21.1, scripting needs DaVinci Resolve Studio.

If something goes wrong, the details are in /Library/Logs/Buddy-install.log.
